Privacy Policy

Effective date: November 5, 2026

This policy explains how Anderson Home Automation (the "app"), a private, self-hosted smart-home application operated by Garet Anderson (the "owner") for his own household, accesses, uses, stores, shares, and deletes data, including data received from Google APIs.

1. Who uses the app

The app is used only by the owner and members of his household whose Google accounts the owner has added. It is not offered to the public, and it has no other users.

2. Google user data the app accesses

Google API and scopeData accessedPurpose
Smart Device Management API
sdm.service		 The household's Nest thermostats: device names, room names, current temperature and humidity, heating/cooling mode, set points, fan and eco settings, and connectivity status. Show thermostat status on the home server and change thermostat settings when a household member asks.
Cloud Pub/Sub API
pubsub		 Event messages that Google sends when a thermostat's status changes. They contain the same kinds of thermostat data listed above. Keep thermostat status current without repeatedly polling Google.
Google Assistant SDK
assistant-sdk-prototype		 The text of commands or announcements a household member chooses to send, and Google Assistant's text reply. Run the household's own Google Assistant commands and broadcasts on request.

The app also stores the OAuth access and refresh tokens that Google issues at sign-in, so it can keep working without asking you to sign in every time. The app does not request or access your email, contacts, calendar, files, photos, location history, or any other Google account data.

3. How the data is used

Google user data is used only to provide the features described above to the household. It is not used for advertising, profiling, or credit decisions, and it is not sold. The app does not use Google user data to develop, improve, or train artificial intelligence or machine learning models.

4. Where the data is stored and how it is protected

  • All data is processed and stored on a home automation server owned by the owner and located in his home. The app has no cloud database of its own.
  • The server is not exposed to the public internet. It is reachable only from the home network and through a private, encrypted network limited to the owner's own devices.
  • OAuth tokens are stored in the server's configuration storage and are never published, logged, or sent anywhere other than to Google when calling Google APIs.
  • Access to the server requires the owner's credentials. Server backups are encrypted with a password and stored on the server itself.

5. Sharing and transfer

Google user data is not shared with, sold to, or transferred to any third party, with these exceptions only:

  • Google itself, when the app calls Google APIs to provide a feature you asked for.
  • Optional AI voice assistant. If a household member uses the app's optional voice assistant powered by Google's Gemini API, the request and the names and current states of the devices the owner has chosen to make available to it (which can include thermostat readings) are sent to Google's Gemini API to answer that request, and are handled under Google's Gemini API terms. A fully local voice assistant that sends nothing outside the home is also available and is the default.
  • When required by law, or to protect the safety of the household.

6. Retention and deletion

  • Thermostat history is kept on the server for about 10 days and then deleted automatically.
  • OAuth tokens are kept until access is revoked or the integration is removed from the server, at which point they are deleted.
  • Encrypted backups are rotated automatically; only the 3 most recent are kept.
  • You can revoke the app's access at any time at myaccount.google.com/permissions. To ask for any stored data to be deleted, email the address below; it will be deleted within 30 days.

7. Google API Services User Data Policy

Anderson Home Automation's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

8. Children

The app is not directed to children and does not knowingly collect data from children.

9. Changes to this policy

If this policy changes, the updated version will be posted on this page with a new effective date.
